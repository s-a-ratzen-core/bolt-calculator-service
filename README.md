# Калькулятор объёма и массы болта (Python + Sanic + Docker)

Учебный проект по расчёту геометрического объёма и массы шестигранного болта (гладкий стержень, резьбовая часть с учётом расчётного диаметра и шестигранная головка). 

Проект демонстрирует перевод консольного скрипта на чистом Python в асинхронный REST API на фреймворке **Sanic**, упакованный в **Docker**.

## Состав репозитория
* `original_cli.py` — исходная консольная версия с пошаговым вводом параметров (`input` / `print`).
* `app.py` — асинхронный веб-сервис на базе фреймворка `Sanic` (`GET /health`, `POST /calculate`) с проверкой входных данных.
* `requirements.txt` — список зависимостей (`sanic`).
* `Dockerfile` — конфигурация для сборки и запуска сервиса в контейнере.

## Запуск в Docker
```bash
docker build -t bolt-calculator .
docker run -p 8000:8000 bolt-calculator
```

## Параметры запроса (`POST /calculate`)
Все геометрические размеры передаются в JSON-теле запроса в **миллиметрах**:

| Параметр | Описание |
| :--- | :--- |
| `dk_mm` | Диаметр стержня болта |
| `hk_mm` | Общая длина стержня |
| `hr_mm` | Длина резьбовой части |
| `sr_mm` | Шаг резьбы |
| `sh_mm` | Размер шестигранной головки под ключ |
| `hh_mm` | Высота головки болта |

## Примеры запросов
Проверка работоспособности сервиса:
```bash
curl http://localhost:8000/health
```

Расчёт объёма и массы (размеры в миллиметрах, пример для болта М12×60):
```bash
curl -X POST http://localhost:8000/calculate \
  -H "Content-Type: application/json" \
  -d '{
    "dk_mm": 12,
    "hk_mm": 60,
    "hr_mm": 30,
    "sr_mm": 1.75,
    "sh_mm": 19,
    "hh_mm": 7.5
  }'
```
